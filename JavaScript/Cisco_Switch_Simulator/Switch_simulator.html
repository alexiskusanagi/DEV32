Histórico de Comandos

Configuração e Status

🛡️ Command Tree - Mapa de Navegação da CLI

Use este mapa mental para entender a hierarquia dos modos de acesso e submodos do Switch Cisco. Cada nível libera comandos específicos!

[Nível 1] Modo Usuário (Switch>)
➔ Comandos livres: ping, exit
➔ Digite: enable
[Nível 15] Modo Privilegiado (Switch#)
➔ Comandos de infraestrutura: show mac address-table, show interfaces status, show vlan brief, show ip interface brief, show running-config, atacar, disable
➔ Comandos de memória: copy running-config startup-config (ou wr), erase startup-config, reload
➔ Digite: configure terminal
Modo Configuração Global (Switch(config)#)
➔ Comandos globais: hostname [nome], banner motd #[msg]#, enable secret [senha], service password-encryption, exit
➔ Digite: line console 0
Submodo Linha Console (Switch(config-line)#)
Comandos: password [senha], login, exit
➔ Digite: line vty 0 15
Submodo Linha VTY (Switch(config-line)#)
Comandos: password [senha], login, exit
➔ Digite: vlan [número]
Submodo Configuração de VLAN (Switch(config-vlan)#)
Comandos: name [nome], exit
➔ Digite: interface vlan 1
Submodo Interface Virtual SVI (Switch(config-if)#)
Comandos: ip address [ip] [máscara], no shutdown, exit
➔ Digite: interface fastethernet 0/[1-5] (ou int fa [1-5])
Submodo Interface Física (Switch(config-if)#)
Comandos de Camada 2: switchport mode access, switchport mode trunk, switchport access vlan [número], exit
Comandos de Segurança: switchport port-security, switchport port-security mac-address sticky, shutdown, no shutdown
